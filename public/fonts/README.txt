Loretta Display (licensed — not included). Two ways to enable it:

1) Adobe Fonts: add Loretta Display to a web project, then paste the kit <link>
   into index.html where marked. The CSS already looks for "loretta-display".

2) Font files: place your licensed web fonts here with exactly these names:
     LorettaDisplay-Light.woff2         — headings & display
     LorettaDisplay-LightItalic.woff2   — italic accent words

Until then the site falls back to Newsreader Light (Google Fonts).
Poppins (body, labels, buttons, navigation) is loaded from Google Fonts — no files needed.
Make sure the licence covers web use on the client's domain.
